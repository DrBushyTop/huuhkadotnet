Due to the Covid-19 situation, the excellent [Global Azure Bootcamp](https://globalazure.net/?ref=huuhka.net) had to be transformed into a virtual event this year. I was already part of organizing a local physical event (which of course was then cancelled), so I thought it would at least make sense to participate in the virtual event.

Here are my presentations from the day. Be sure to check out the rest of the sessions on the site. Links can be found at the end of this post.

<a id="take-control-of-your-deployments-with-azure-pipelines-yaml" />

### Take control of your deployments with Azure Pipelines & YAML

<iframe src="https://www.youtube.com/embed/Fg5-NJwMZ9o?feature=oembed" title="Embedded presentation video" loading="lazy" allowFullScreen />

Infrastructure as Code in ARM templates, scripts required in configuration... Little by little, every piece of the puzzle required to get your code into production is becoming a part of the same repository. Now with Azure Pipelines YAML, the last piece - your whole deployment workflow - can be included there as well!

Join Pasi Huuhka as he walks through the most useful features of Azure Pipelines with the YAML schema and how to use them. He will also provide real world insight into what he has found to be the best way to transition from classic pipelines to YAML, pros & cons and YAML pipeline development workflow & tooling.

Are you ready to start mastering Azure Pipelines YAML? This session will set you on the right path.

<a id="develop-deploy-on-azure-data-factory-and-databricks" />

### Develop & Deploy on Azure Data Factory and Databricks

<iframe src="https://www.youtube.com/embed/E9-Yblr5XAY?feature=oembed" title="Embedded presentation video" loading="lazy" allowFullScreen />

Two of the essential services in the Azure Data story - Azure Data Factory v2 and Azure Databricks – are fairly easy to take in use in development, but how do you actually deploy to production with them?

Join Pasi Huuhka as he walks through the inner workings of these services, how to automate their deployments and troubleshoot them when you run into issues. Sprinkled with real world experience, the session will go through the best development practices, suggested ARM template structures, deployment pipelines and much more!

After this presentation you too are ready to create your own functional CI/CD flow for your data services.
