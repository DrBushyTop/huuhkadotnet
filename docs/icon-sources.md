# Icon sources

The Sessionize path in `src/components/Icon.astro` comes from Simple Icons,
retrieved September 21, 2026. It is bundled inline, with no external image request
or icon-library dependency. Brand rights remain with their respective owners.

- Source: https://github.com/simple-icons/simple-icons/blob/develop/icons/sessionize.svg
- License: https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md

The Microsoft Foundry icon at `public/images/icons/azure-ai-foundry.svg` is
`035746832-icon-service-AI-Foundry.svg` from Microsoft's Azure Public Service Icons V24,
retrieved October 25, 2026, unmodified. Microsoft permits these icons in architecture
diagrams, training materials, and documentation. It's used in the article diagrams through
`src/components/DiagramIcon.astro`. Other diagram icons there are authored for this site.

- Source: https://learn.microsoft.com/en-us/azure/architecture/icons/
- Terms: the icon terms on that page and the Microsoft_Terms_of_Use.pdf in the download
